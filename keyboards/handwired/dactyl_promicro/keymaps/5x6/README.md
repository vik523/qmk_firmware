# Dactyl 5x6 — снегирь на OLED

На вертикальном OLED 128×32 живёт снегирь на ветке рябины. Вместо надписей QWR/NUM/CAP
состояние клавиатуры показывают детали сцены.

![Превью](demo/preview.gif)

**Живое демо:** откройте [`demo/bullfinch-demo.html`](demo/bullfinch-demo.html) в браузере (скачайте файл
или включите GitHub Pages). Там работает тот же `bullfinch.c`, что в прошивке, собранный
в WebAssembly: можно печатать, переключать слои, локи и время суток.

| Что на экране | Что означает |
|---|---|
| Снегирь на средней / нижней / верхней ветке | Слой QWR / LWR / RSE |
| Снегирь с ягодой в клюве | Слой NUM |
| Снегирь в полёте | Слой ADJ (LOWER + RAISE) |
| Снежная шапка | Caps Lock |
| Светящиеся ягоды | Num Lock |
| Фонарик под веткой | Scroll Lock |
| Надпись на сугробе | Последняя нажатая клавиша |
| Месяц / солнце / закат | Время суток |

Через 30 секунд без нажатий снегирь засыпает, через 5 минут экран гаснет.
Раз в 45 секунд с грозди падает ягода.

## Сборка

```
make handwired/dactyl_promicro:5x6
```

Прошивка занимает около 27 КБ из 28 КБ (ATmega32U4, свободно ~1,1 КБ, с `RAW_ENABLE` ~0,8 КБ).
Помещается благодаря `LTO_ENABLE = yes`, `MAGIC_ENABLE = no`, `MOUSEKEY_ENABLE = no`
и тому, что сцена рисуется своим шрифтом 3×5 без стандартного шрифта OLED.

Если картинка перевёрнута, замените в `keymap.c` `OLED_ROTATION_90` на `OLED_ROTATION_270`.

## Клавиши

- **Скролл трекболом:** держите RAISE и крутите шар — страница прокручивается
  (подробнее в разделе «Трекбол»).
- **Переключение языка:** правый большой палец, рядом с Enter. По умолчанию Win+Space,
  другое сочетание задаётся в `keymap.c` (`#define LANG_SW`).
- **RAISE + X** — Alt+F4 (закрыть окно).

**Прошивайте обе половины.** Раскладку обрабатывает половина с USB, а экран может стоять
на другой: если обновить только одну, новые сочетания или надпись на сугробе не заработают.

## Слои

- **ADJ** — зажать LOWER и RAISE одновременно. На нём: `SKY_NEXT` (смена неба),
  `TG(_NUM)` (цифровой блок), `QK_BOOT`.
- **NUM** — фиксируется, пока не выключишь: нумпад справа, выход тем же `TG(_NUM)`.

## Трекбол (`trackball.c`)

- **Слой мыши включается сам**, когда двигается шар, и гаснет через 0,65 с после остановки
  или от любой обычной клавиши — печатать можно сразу. Кнопки продублированы на обеих руках:

  | Клавиша | Действие |
  |---|---|
  | F / J | левая кнопка |
  | S / L | правая кнопка |
  | D / K | средняя кнопка |
  | G / H (`TB_SCRL`) | держать — шар крутит страницу |
  | A / ; (`TB_SNIP`) | держать — курсор в 4 раза медленнее, для точного выделения |
  | C V / M , | «назад» / «вперёд» |
  | B / N (`TB_SCLK`) | скролл включён/выключен (защёлка) |

- **Скролл** (RAISE или `TB_SCRL`) замедлен делителем и идёт по одной оси: первое движение
  выбирает вертикаль или горизонталь, страница не уезжает вбок. Прокрутка слой мыши не
  включает, так что стрелки на RAISE остаются на месте.
- **Чувствительность** — на слое ADJ: D (`TB_CPID`) и F (`TB_CPIU`) во втором ряду снизу
  меняют CPI шагом 200 (от 200 до 4000). Значение хранится в EEPROM и переживает
  отключение кабеля; начальное — `PMW33XX_CPI` (1200). Там же G (`TB_AUTO`) выключает
  автослой мыши, например для игр.
- Снегирь слой мыши не замечает: при движении шара сцена не меняется.

Настройки в `config.h`: `AUTO_MOUSE_THRESHOLD`, `AUTO_MOUSE_TIME`, `TB_SCROLL_DIV`,
`TB_SNIPE_DIV`, `TB_SCROLL_INVERT_V` (если скролл идёт не туда), `TB_SCROLL_NO_AXIS_LOCK`.

## Время суток с компьютера (необязательно)

1. В `rules.mk` раскомментировать `RAW_ENABLE = yes` (+300 байт).
2. `pip install hidapi`
3. Запустить `python bullfinch_time.py` (можно в автозагрузку).

Без скрипта небо переключается клавишей `SKY_NEXT`.

## Настройки (`config.h`)

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `BF_SLEEP_MS` | 30000 | Через сколько мс простоя снегирь засыпает |
| `BF_OFF_MS` | 300000 | Через сколько мс простоя гаснет экран |
| `BF_BERRY_EVERY` | 450 | Раз в сколько кадров (по 100 мс) падает ягода |
| `BF_FRAME_MS` | 100 | Период анимации |

## Файлы

- `bullfinch.c`, `bullfinch.h`, `bf_data.inc` — сцена и спрайты
- `bullfinch_time.py` — отправка часа с компьютера по Raw HID
- `trackball.c`, `trackball.h` — скролл, точный режим, CPI, автослой мыши
- `flash_caterina.ps1` — прошивка готового `.hex` через avrdude без пересборки
  (ждёт загрузчик сам; запускать по разу на каждую половину)
- `dactyl-5x6-shpargalka.html` — шпаргалка по слоям на один лист A4 (альбомный):
  открыть в браузере и напечатать в PDF
- `demo/` — браузерное демо; `demo/build.sh` пересобирает его из текущего `bullfinch.c`
  (нужны `clang` и `wasm-ld`)
